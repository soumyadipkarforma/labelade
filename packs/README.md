# Community label packs

Each file here holds labels for one app, named `<app>.json`. To use one, download it and import it: NVDA menu, Tools, Labelade, Import a label pack.

There are no packs yet. Be the first: see [docs/LABEL-PACKS.md](../docs/LABEL-PACKS.md) for how to make and share one. Packs must contain real labels from real use, checked by a person.
